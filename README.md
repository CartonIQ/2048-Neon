# 🎮 2048 Neon - Puzzle Game

**2048 Neon** is a premium, 100% offline Android puzzle game with a stunning neon glassmorphism UI, smooth tile animations, haptic feedback, and satisfying sound effects.

## ✨ Features

- 🎮 **Classic 2048 Gameplay:** Swipe to merge tiles and reach 2048.
- ✨ **Smooth Animations:** Tiles glide and pop when merging.
- 📳 **Haptic Feedback:** Feel every merge.
- 🔊 **Sound Effects:** Satisfying click sounds.
- 🎊 **Confetti Celebration:** Victory animation at 2048.
- 💎 **Glassmorphism UI:** Floating bottom dock, neon glow.
- 🌗 **Dark & Light Mode:** Full theme support.
- 📊 **Stats & Leaderboard:** Track your best scores.
- ⏪ **Undo & Hint:** Watch a rewarded ad to use.
- 🔒 **100% Offline:** No internet required to play.

## 🚀 Installation

1. Go to the **[Releases](https://github.com/CartonIQ/2048-Neon/releases)** page.
2. Download the latest `Neon2048-Signed.apk`.
3. Open and install (allow "Install from unknown sources").

## 🛠️ Built With

- **Language:** Kotlin
- **UI:** Material 3, ViewBinding, Custom Glassmorphism
- **Architecture:** MVVM, Navigation Component
- **Local Database:** Room DB
- **Monetization:** Google AdMob (Banner, Interstitial, Rewarded)
